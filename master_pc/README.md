# master_pc

Esta carpeta contiene el codigo Python que los estudiantes SI deben modificar para resolver el reto.

## Configuracion obligatoria

Antes de ejecutar, configure la direccion Bluetooth del robot en el codigo Python.

En main.py, cambie la MAC usada al crear el robot:

- Robot("00:1B:10:21:2C:1B")

Reemplace ese valor por la direccion Bluetooth real del mBot que van a controlar.

## Archivos principales

- main.py: captura de camara y logica principal.
- Robot.py: conexion Bluetooth y envio de comandos.

## Regla para estudiantes

Trabajar solo en esta carpeta.
No modificar actuadores_arduino.
